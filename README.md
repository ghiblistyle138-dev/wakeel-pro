# Wakeel Pro

**Legal Drafting, Case Management and Research in Urdu and English.**

Official download page for the Wakeel Pro desktop software for Pakistani lawyers.

## Download

Get the latest version from the **Releases** section of this page:

**https://github.com/ghiblistyle138-dev/wakeel-pro/releases/latest/download/WakeelPro-Setup.exe**

1. Download `WakeelPro-Setup.exe`
2. Run it (if Windows asks, choose **More info → Run anyway**)
3. Start the software and begin your free trial, or activate with your license key

## Features

- Urdu and English legal drafting with ready templates and 60 drafting styles
- Urdu voice dictation (offline) and voice notes
- Complete CPC and CrPC library with search
- Case management with hearing reminders
- OCR for scanned documents, online Urdu↔English translation
